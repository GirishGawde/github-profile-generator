# GitHub Profile Generator 🚀

A professional developer tool that visualizes GitHub profiles using the GitHub API.

## 🌟 Features
- **Smart Search:** Instantly fetches user data and repositories.
- **Visual Analytics:** Displays a Chart.js doughnut graph of the user's top languages.
- **Glassmorphism UI:** A modern, dark-themed design built with CSS variables.
- **Responsive:** Works on mobile and desktop (Dashboard layout).

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **API:** GitHub REST API
- **Libraries:** Chart.js, JetBrains Mono Font
